# Ember & Spice

A small, responsive restaurant storefront demo for a fictional non-vegetarian restaurant. Browse a menu, filter dishes, add items to a persistent shopping bag, and walk through a demo checkout.

## Run locally

Open `index.html` in a browser, or serve this folder with a static file server. No build step or dependencies are required.

## Deploy on GitHub Pages

To deploy this site on GitHub Pages:

1. Push this project to your GitHub repository.
2. Go to the repo on GitHub.
3. Open Settings → Pages.
4. Under Build and deployment, set the source to GitHub Actions.
5. Commit the workflow file in `.github/workflows/pages.yml`.
6. Push to `main`.
7. GitHub Actions will build and deploy automatically.

## Demo notes

- This is a front-end demo: checkout does not submit orders or collect payments.
- Menu prices and restaurant details are sample content.
- Food photography is loaded from Unsplash, and fonts are loaded from Google Fonts.
